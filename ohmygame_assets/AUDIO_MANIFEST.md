# Audio Manifest — Đấu Trường Nhân Quả M1 (VN/CN/JP)

Procedural WAVs, generated by `~/workspace/tools/game-audio/generate_sfx.py`
(seed 20261121, deterministic — re-running produces byte-identical files).
Format for every file: 44.1 kHz, mono, 16-bit PCM, peak normalized to -3 dB (0.707), no clipping.
Total: 52 files, 111.6s.

Staging only: files live in `ohmygame_assets/` (this folder). They are NOT yet in
`assets/` — run the OhMyGame/Fennara sync script to copy validated files there.
Do not hand-edit these WAVs; regenerate via the script.
